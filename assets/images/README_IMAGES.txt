ILLUSTRATIONS — already installed
=================================
These 6 mascots are already placed in the app (cut from your artwork,
made into round stickers with transparent edges):

  hippo.png   -> home banner ("Let's learn today!")
  sun.png     -> lesson "Watch" panel
  cat.png     -> lesson "Practice" (quiz) header
  star.png    -> "Well done!" completion popup
  trophy.png  -> My Progress screen
  chick.png   -> login / welcome screen

TO SWAP any character: replace the file here with a new PNG of the SAME name.
TO RESIZE: in the screen file, change the number in  AppImage('name.png', width: 96)
TO ADD A WHITE RING: AppImage('name.png', width: 96, ring: true)

SOUNDS (in assets/sounds/):
  correct.wav   -> plays on a correct quiz answer
  wrong.wav     -> plays on a wrong quiz answer
  complete.wav  -> plays when a lesson is marked complete
